# Odin Recipes

This is a simple project from [The Odin Project](https://www.theodinproject.com/) curriculum.  
The goal of this project is to build a basic recipe website using only **HTML** (and later improve it with **CSS** and **JavaScript**).

## Skills Demonstrated
- Structuring a webpage with HTML
- Creating and linking multiple pages together
- Using lists, headings, images, and links
- Organizing a project with Git and GitHub

## Reflection
By the end of this project, I will have practiced:
- Writing clean and semantic HTML
- Tracking changes with Git commits
- Hosting and sharing my code on GitHub
